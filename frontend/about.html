About PisteLens

The problem

Every ski resort grades its own runs, and every resort does it differently. An intermediate run at one resort might feel like an advanced run at another, so a grade on a trail map does not tell you much when you visit somewhere new.

The goal

PisteLens gives every run a fair, comparable difficulty based only on its terrain, so you can tell how hard a run really is before you get to the top of it.

How it works

Global rating. Using piste data from OpenStreetMap, PisteLens measures each run's terrain: its length, how steep it is on average and at its steepest, how much the steepness changes, how much it winds, and how it is groomed. A machine learning model trained on thousands of runs turns these measurements into a global rating from 0 (novice) to 5 (extreme). Because it only looks at the terrain, the rating means the same thing at every resort.

Calibration. PisteLens also learns how strict or generous each resort is with its grades. Pick a resort you know, and any run's global rating can be converted into the grade that resort would probably give it, in terms you are already used to.

What you can do

  • Search runs by name, resort, grade, length and grooming on the Home page.
  • Grade your own route from a GPX file or its terrain features on the Advanced Tools page.
  • Download the full dataset and model on the Data page.

PisteLens is a guide, not a guarantee. Snow, weather and your own skill all change how hard a run feels on the day.
